# Roadmap

After the 1.0 release gates: complete distributed PostgreSQL-backed admission control and cross-replica SSE notification/replay; add richer reconciliation batch persistence and merge reversal tooling; extend graph query planning and policy UI; build supported cloud/virtualization/NetBox/ServiceNow/Ansible adapters one at a time with data-minimization reviews; add Vault/cloud secret-store implementations; expand artifact lifecycle verification; and publish representative performance/recovery reports.

Roadmap items are not current capabilities. Each connector requires real read-only integration tests, a permission manifest, threat-model update, provenance contract, and secret-exclusion tests before documentation may call it supported.
